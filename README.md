# attendance
the place for people to check in. 

This check in sheet use the script from the google document:#https://docs.google.com/spreadsheets/d/1e3haWAusOxtRWa_k2xUwdlql3YH8TMVKYmpzXmXh2Zg/edit?gid=0#gid=0
It is a temporary place to store OML's big event check in data. Once the event end, please transfer the data to appropriate documentation. 

The table contains four columns (name, school, status (registration status), checked in, and notes)

Once people check in, the record will automatically uploaded to this google sheet.
